## Introduction
Data engineering is an essential part of working with data in the modern world. This repository contains hands-on projects that demonstrate how to automate workflows, process data, and develop scripts to work with data pipelines effectively.

## Skills Covered
By working through these projects, you'll develop skills in:
- Bash shell scripting
- ETL process implementation (Extract, Transform, Load)
- File handling and data manipulation
- Basic data engineering techniques

---

## Projects Overview
1. **File Processing with Bash**: Automate file renaming, sorting, and organization using Bash scripts.
2. **Simple ETL Pipeline**: Extract data from CSV files, transform it into a structured format, and load it into a database.
3. **Log Analysis**: Parse server logs using Python and Bash scripts to generate insights.
4. **Data Validation Script**: Pre-process and validate the quality of data in files using basic scripting techniques.
